# Contributing to Nihongo Grove

Small improvements to the hub are welcome. Keep the interface in English and the learning content about Japanese.

## Make a change

1. Fork the repository and work on a branch.
2. Edit files in `public`. No build step is required.
3. Run a static server as described in the README and check the page in a browser.
4. Open a pull request describing the user-visible change and what you checked.

## Keep the hub useful

- Preserve readable text, keyboard focus, reduced-motion support, and usable touch targets.
- Keep essential navigation working without JavaScript.
- Use ordinary HTML links to the learning apps. Label unfinished projects as in development.
- Describe real features; do not add fabricated scores, progress, reviews, or learning claims.
- Use original assets or include the appropriate license and attribution for third-party assets.
- Keep credentials, personal details, account screenshots, and private administration files out of commits.

Before submitting, check a narrow mobile layout and a desktop layout, follow the app links, and verify the canonical URL and social metadata if you changed the page head.
